Accessibility + contrast

Not color-only: filled = done (solid with inner dot), current = larger 14px + pulse ring + shadow, hollow = future ring only, stalled = amber with ! mark, failed loop = warn border + fail state pill. All have text label under dots (stage name + 3/8 count + state pill).
Text alternative: each dot has aria-label, progress container has aria-label with current stage, sr-only text lists all stages with done/current.
Contrast: --text #3d3d3d on #ffffff 10.8:1, --muted #6b6b6b on #ffffff 5.7:1, --accent-fg #1e3a26 on #86d9a0 8:1, warn #8a4a0a on #ffe9d0 7:1, danger #9a1a24 on #ffe2e6 8:1, all pills meet 4.5:1 in light and dark.
Motion: pulse and shake respect prefers-reduced-motion, animation disabled when set.
Focus: tooltip shows on hover and focus-within, keyboard Tab reaches exec-wrap, focus ring visible.
