Design notes

This mockup shows all AI panel states in a 380px panel with Sprout look (cream #f5edde, white soft-shadow cards, mint #86d9a0). No external files, no HTML injection, keyboard accessible, contrast ≥4.5:1.

Reusable components

  • .card base + variants .proposal .receipt.done .error — proposal, receipt, error, memory drawer all share
  • .btn primary / small / tiny / ghost — Approve, Undo, View board, Retry, Forget
  • .chip pill — quick replies, state switcher, feedback reasons
  • .bubble + .msg — user and assistant turns
  • .steps + .step + .spinner — working live progress
  • .feedback + .icon-btn + .feedback-panel — thumbs and reason chips
  • .memory-chip + .memory-drawer — remembered facts

Accessibility

  • Focus rings via :focus-visible, tablist for states, aria-selected, aria-controls, aria-labels on all icon buttons, aria-live for copy feedback
  • Text contrast: #3d3d3d on #ffffff 10.8:1, #6b6b6b on #ffffff 5.7:1, #1e3a26 on #86d9a0 8.1:1
  • Spinner respects prefers-reduced-motion

Dark mode

Toggle sets html[data-theme=dark], all tokens swap, same shadows removed, mint stays primary but text adapts.
